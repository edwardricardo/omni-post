## A-TEAM Members, roles and access

24 features as read: PARTIAL 15, BACKEND-ONLY 5, DEAD 3, END-TO-END 1.

Main findings:

- Single sign-on cannot work for Members as the code is written, and customer API keys always answer unauthorised.
- Invitations have no accept step, and only 2 of 46 seeded customer permissions are enforced by a route.
- Two security leads to verify: a team route takes the acting Member's id from the request body; a notifications route lets a Member write to any user id.
