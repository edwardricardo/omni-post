# CI cache integrity audit

**Date:** 2026-08-17
**Scope:** GitHub Actions caches (`.turbo`, the pnpm store), Turborepo's input hash, `outputs` coverage, non-Actions caches (BuildKit, knip) and the retention workflow (`cleanup.yml`).
**Method:** every claim is backed by `file:line` or by a command and its real output. Every finding went through an independent adversarial verification; 11 candidates were refuted and are listed at the end so nobody reinvestigates them.

---

## 1. Verdict in one line

**YES.** The cache can let a gate pass that should fail: a `turbo` run was reproduced, on the repo's real cache, with `Tasks: 2 successful / 2 cached / >>> FULL TURBO` and exit zero, that left `infra/prisma/dist/src` with **0 files** — an empty artifact blessed under a new hash and served indefinitely (OC-2). The mechanism was confirmed a second time on a controlled bench: a commit that changes only `tsconfig.build.base.json` (`ES5 → ES2020`) got `cache hit, replaying logs`, exit 0, and a `dist` compiled with the **previous** configuration (NAC-02).

An equally important corollary: the incident that started this audit (PR #189, `TS2724 'TrackedLinkId'`) was a **false red**, and its transport vector was proven live — the catch-all `restore-key` `${{ runner.os }}-turbo-` served the 6 CI jobs a `.turbo` built on `main`, against **another** `pnpm-lock.yaml` (AC-1).

**Honest limit:** the transport vector is proven; the _genesis_ of that incident's stale `@core/domain` entry is not. The two hypotheses that explained it (TH-1, TH-2) were refuted empirically. What is proven are three independent genesis paths for poisoned entries (OC-2, OC-3 local, TH-3 by concurrent write).

## 3. The false greens, separately

> A gate that cannot fail is not a gate. This section is separated on purpose: a false red costs a run; a false green lets a broken commit through.

### 3.1 **Proven** false green — immediate action

| ID         | Sev.     | What it lets through                                                                                                                                                                    | Proof                                                                                                                                                                                                                                                                                                                                                   |
| ---------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OC-2**   | CRITICAL | A completely green `build` run that produces **zero compiled output**, re-blessed under a new hash and self-propagating                                                                 | Entry `24c57450fd9c779a` written with 404 files and `dist/src` = 0; when re-served: `2 cached, 2 total / >>> FULL TURBO` and the destruction of a healthy `dist` (18 → 0 files). Repair-proof: neither the build itself nor the consumer's `tsc -b` rebuilds it                                                                                         |
| **NAC-02** | MEDIUM   | A compiler-settings change (`skipLibCheck`, `target`, `module`, `declaration`, `composite`) that no compiler ever executes; the `dist` the gate consumes comes from the previous config | End-to-end repro: committed config `ES2020`, served artifact `ES5 skipLibCheck=false`, exit 0. An amplifier the original finding did not see: the hash is **per package**, so a mixed commit (config + 1 package) still replays the other 78 from the cache — it is a partial false green on _every_ config edit, far more reachable than the pure case |

**Existing mitigation that does work (do not break it):** `turbo run typecheck` (`ci.yml:44`) is correctly hashed — each `typecheck` is `tsc --noEmit` over `tsconfig.json`, which extends `tsconfig.base.json`, which is declared as a global dependency. Source-level type errors are still detected. NAC-02's blind spot is limited to _emit_ semantics: `.d.ts`, `composite`, `target`/`module`/`moduleResolution`, `skipLibCheck` over the dependencies' `.d.ts` files.

### 3.2 **Structural, unobserved** false green

- **AC-1** — the symmetry is real: the same 28 replayed `build` artifacts feed Build Check, the 165-task typecheck gate and the Package Tests dependency closure in a single run, so a stale `dist` that keeps a deleted export would pass all three. **I found no observed instance.** The false-green direction stays marked UNVERIFIED; the false-red one is proven.

### 3.3 **Bounded or latent** false green — they block no code

- **AC-3** (MEDIUM) — the job lies `✅ Completed` weekly without deleting anything, but `needs.cleanup-caches.result` is consumed only in the summary table (`cleanup.yml:292`). No branch protection, PR check or build gate reads it. Real cost: unbounded growth (174 caches, 1939 artifacts at the time of the incident) and zero signal on a permission regression. **Warning:** fixing it does **not** close the turbo poisoning — the key embeds `${{ github.sha }}`, so the stale content migrates to an entry minutes old on every run, and a `created_at < now-7d` filter can never select it (verified: `rg -c 'Failed to delete cache Linux-turbo'` = 0 in the 5 runs inspected).
- **NAC-05** (LOW) — the SARIF certifies an image that is then discarded and rebuilt. Today nothing is pushed (32/32 instances skipped the push) and nothing in the repo consumes the image. Hygiene to close **before** resuming the containerization workstream.

### 3.4 False red / integrity (harmful, but lets nothing through)

- **AC-1** — proven with the `TS2724` of attempt 1 of run `32062485695`.
- **TH-3** — nondeterministic spurious failures on clean sources (2/11): `TS1010`, `TS2306`. The same family as the incident's `TS2724` (a half-written barrel).
- **OC-3** — `TS2307` in the consumer, only in the local workspace; CI reachability zero.
- **TH-4** — it is neither a false green nor a false red: CI faithfully builds a tree that is missing the file. The damage is a broken sidebar link deployed in every build and a 16 KB feature that exists only on one disk, unrecoverable from git.
