# Design: Testing Re-foundation (`testing-refoundation`)

**Change:** `testing-refoundation` · **Date:** 2026-09-27 · **Phase:** design (revision 2, after the gate review in Engram `sdd/testing-refoundation/design-gate-findings`) · **Inputs (settled, not re-opened):** proposal (`proposal.md`, Engram #960), the approved plan `/root/.claude/plans/lazy-swinging-moon.md` (14 points, D1-D20, ~130 WUs), research (`research.md`), exploration (`exploration.md`), handoff (Engram #958), and the specs written in parallel (`specs/*/spec.md`; this design follows `integration-tier-preconditions` for the outbox topology and `test-environment-contract` for E2E server ownership). Where the plan left an implementation choice open it is decided here (§3, DD-1..DD-24) with the alternative and the reason. Work units are cited by id; the plan holds their full text.

**Revision 2 in one paragraph.** The DB-only tier runs before the application boots and the live tier after, under one trap (`test-env.sh integration`, DD-19); Playwright owns the E2E processes through `test-env.sh serve`, CI never starts them twice (DD-18); four configs, not one, sit outside the factory today and each migrates to it with factory-owned arrays that REPLACE rather than concatenate (DD-20); a file is "reached" only by a collector whose job exists and is required, so a collector may declare `executedBy: []` until its job lands (DD-21); Node ships no `json` test reporter, so DD-7's custom reporter is the only design; the probe key gains the file's non-block bytes (DD-5); the Prisma double's raw-SQL throw is preceded by a measurement of who reaches it, and the unit/route tier's answer is decided by that measurement (DD-17); the threat matrix gains four rows (subprocess lifecycle, destructive DB target, CI automation that writes to GitHub, worktree lifecycle) with the probe root and `HEAD` checkout defined (DD-22); the identity red plants a caller-environment URL, not a nonexistent input (DD-23); the k6 job's final shape is stated (DD-24). Every file:line below was opened at the source in this run.

## 1. Technical approach

Five frameworks become one system by sharing three contracts and one tooling layer; no runner calls another. **The unit is the composition of the merge gate.** Every component below is fail-closed (P5), ships with its red demonstrated on the complete step (P4), and replaces a default with a refusal (P3).

```
                     ┌────────────────────────── VERDICT ──────────────────────────┐
                     │ .github/rulesets/main.json  ◄── #45 V6 drift (push/nightly)  │
                     │ required contexts, strict     ▲                             │
                     └───────┬──────────┬────────────┼──────────┬──────────┬───────┘
   ci.yml jobs:   Test Suite│ Coverage │Integration  │ Package  │ E2E      │ k6 (performance.yml)
                  (shards)  │ Merge    │ Tests       │ Tests    │(chromium)│
                     │      │          │ (2 phases)  │          │          │
   REACH  ──►  packages/test-contracts  (Test Contracts job in fitness.yml: #30 #32 #36 #37 #45 #47)
               reach.ts ◄── collectors.json · quarantine.json · run-tests.sh --list · vitest createVitest
                     │                       ▲                      ▲
   ENV    ──►  scripts/test-env.sh  (env|db|up|serve|down|liveness|logs|run|integration)
               run: env → db → [before-up cmd] → up → cmd → liveness → down   (one trap)
               Playwright webServer ──► test-env.sh serve <proc>   (CI runs env + db, then playwright test)
               .env.test (generated) ──► vitest-shared loadTestEnv ──► every vitest config (86)
                     │
   TOOLING ──► packages/vitest-shared (factory: excludes · reporters · skip-gate · coverage · setupFiles · conditions)
               packages/test-utils/{domain,wire,persistence} · apps/api/tests/support/buildRouteTestApp
               packages/eslint-plugin-testing (classifier) ◄── scripts/testing/{ledger,hard-probe,metrics,mutation}.mjs
```

Dependency direction (build graph, `^build`): `@test-utils/domain` → `@core/domain`, `@shared/types` · `@test-utils/wire` → `msw`, `@shared/types` · `@test-utils/persistence` → `@infra/prisma`, `vitest`, `ioredis` types. Nothing under `**/src/**` imports `@test-utils/*` (depcruise gate). `@packages/vitest-shared` declares no workspace dependency (it reaches `tsconfig.base.json`, `vitest-entry.ts` and the wire setup file **by path**, DD-6). `packages/test-contracts` and `packages/eslint-plugin-testing` are private, source-only, no build script (same model as `vitest-shared`, ADR-0017: config-time tooling, `dist` would only go stale; no build script at all, so fitness #35 is not engaged). NodeNext (api/workers) and bundler (Next apps) stay split; the tooling packages are consumed by vite/tsx from source and never enter an app build graph. `pnpm-workspace.yaml` gains the glob `packages/test-utils/*` (today's `packages/*` is one level deep and would not see the three packages).

**Test-shaped** = basename matches `/\.(test|spec)\.[cm]?[jt]sx?(\..+)?$/` or `/\.k6\.js$/` (catches `.test.ts.disabled`, `.old`; excludes `.env.test.example`). Disk set = `git ls-files` of the whole repository.

**Router** (`collectorOf`): `*.integration.test.ts` → `node:integration` (only under `apps/api/tests/**`) · `*.live.test.ts` → `node:live` (same) · `*.spec.ts(x)` → `playwright:<app>` (only under `apps/{client,admin}/**/e2e/**`) · `*.k6.js` → `k6` · `*.fixture.ts`, `*.test-helpers.ts` → `none` by design · any other test-shaped → `vitest:<package>` (the package whose config collects it) · unresolvable → `null`. The suffix names the **tier, not the runner**, so the router survives X2 either way.

**Rules.** _Reached_ = collected by exactly one collector **whose `executedBy` is non-empty and whose every job exists and is required** (DD-21). R1 every test-shaped file on disk is reached exactly once or is quarantined (`disk − ⋃reached − quarantine = ∅`; `|collectors(f)| ≤ 1` counting every collector, executed or not, so a file listed by two collectors is "collected twice" even if one has no job). R2 for each entry of a non-empty `executedBy`: the job exists, its `run:` contains the entrypoint, its rendered `name` (matrix expanded) is a required context in `.github/rulesets/main.json`; for a **phased** entry the engine additionally reads the `integration` recipe in `scripts/test-env.sh` and asserts that `TIER=pr-integration` precedes the `up` call and `TIER=live-integration` follows it (textual order inside the recipe function; recipe not found → fail closed). R3 every quarantine entry exists on disk, is collected by **no executed collector** (a collector with `executedBy: []` may list it — that is the case the quarantine exists for), and `head ⊆ base` (read via `git show <base>:packages/test-contracts/quarantine.json`; on push runs base = `HEAD~1`). Part B (WU-1.14): no `vitest|node --test|playwright test|k6 run` with a positional path in any workflow except the registered forms; every `pnpm … test*` / `turbo run test*` script is one of `test`, `test:coverage`, `test:integration`, `test:e2e`. Part C (WU-1.11): every package with a vitest config has `scripts.test === "vitest run"` and (from Phase 5) `scripts["test:coverage"] === "vitest run --coverage"`; no package config sets a factory-owned key — the SAME set §2e names: `test.reporters`, `coverage.provider`, `coverage.reporter`, `coverage.reportsDirectory`, `coverage.include`, `resolve.alias` — neither in the factory's `overrides` argument nor in the outer `defineConfig({...})` argument of the `mergeConfig` shape (§2e), because that outer argument bypasses the factory's runtime refusal and this static check is the only guard there (DD-20). **Serial-tier invariant**: `run-tests.sh` never passes `--test-concurrency` > 1 and runs one file per process (asserted by reading the script and by `--list` count = process count in the behaviour test). Fail-closed conditions: disk < 800 · configs < 80 · any collector returns 0 · a config that does not resolve · a non-empty `executedBy` naming a missing job/workflow · ruleset file missing or with 0 contexts · base quarantine unreadable · a phased entry whose recipe cannot be found. Red-proofs (WU-1.10): orphan file → "unreached"; a second config including a file → "collected twice"; a file collected by an executed collector added to quarantine → exit 1; deleted quarantined file → exit 1; `collectors.json` → fake job → exit 1; swap the two `TIER=` lines in the recipe → "phase order" exit 1; each restored by `sha256sum`.

**Skips (#32, `skips.ts`)**: `ts.createSourceFile` (no type-check) over every test-shaped file; flags member access `.(skip|only|fixme|todo|skipIf|runIf)` on `it|test|describe|suite|test.describe` (called or referenced), `skip|only|todo` keys in a 2nd-arg options object, Playwright `test.skip(`/`test.fixme(` anywhere. Prisma `{ skip: 2 }` inside a non-test call is not flagged (red-proof (d)). `.todo` is a skip (D3). Runtime `t.skip()` is gated by the runner (`run_file`) and by `skipGateReporter` for vitest.

Rules `testing/no-empty-test`, `testing/no-tautological-assertion`, `testing/no-existence-only-test` call `classifyFile(context.sourceCode.text, filename)` in the `Program` visitor and report by `loc`; only classes calibrated ≥ 90 % GREEN by the probe become rules (TITLE-CONTRADICTION stays ledger-only). Fixtures: positive + negative per class per framework (incl. `auditMiddleware.test.ts:274`, `webhookHandler.stats.test.ts:355`). Bulk suppressions: `eslint-suppressions.json` at root, rules pinned at `error` (#48, form of #31 B: a rule not at `error` → exit 1); a stale suppression makes a plain `eslint` run exit 2 (ESLint 9.36.0), and `eslint --prune-suppressions` is the command that removes it (prune obligatory per demolition slice). `vitest/*` rules (`expect-expect` with `assertFunctionNames: ["expect","expect*","assert","assert.*","expectTypeOf"]` — wildcard verified on one file first, `no-conditional-expect`, `valid-expect`, `no-standalone-expect`, `no-identical-title`, `no-commented-out-tests`, `no-disabled-tests`, `no-focused-tests`) apply only to the files vitest collects (`collectorOf` startsWith `vitest:`), never to node:test files; `no-console: error` on all test globs.

**Hard probe** (`scripts/testing/hard-probe.mjs`, an **orchestrator tool** — writers never invoke it, D19): one detached worktree under the **probe root** (DD-22: CI `$RUNNER_TEMP/hard-probe/<run-id>`; homelab `<repo-parent>/<repo-name>-worktrees/hard-probe-<pid>`, a sibling of the repository, never `/tmp` and never inside the repository; `HARD_PROBE_ROOT` overrides both and is validated absolute, existing, writable and outside the repository) created with `git worktree add --detach <dir> HEAD` — **`HEAD` of the invoking checkout**, so a 6.N writer's test is probed only after the orchestrator has committed it in that writer's worktree, and the writer's "probe RED" acceptance is verified by the orchestrator rather than self-reported; `pnpm install --offline --frozen-lockfile`; subject = the test's first-party imports resolving into `src/`; gut with `ts.transform` (every exported function/method body → `throw new Error("__HARD_PROBE__")`, top-level statements intact); run **only that block** (`vitest run <file> -t "<title>" --reporter=json` / `node --test --test-name-pattern`); outcome GREEN = decorative (d) · RED = restricts (weak evidence) · LOAD-ERROR = inconclusive; restore `git checkout -- .` inside the probe worktree and assert its `git status --porcelain` empty; the worktree is removed and pruned under a trap (§5); the invoking tree is never written (its porcelain is captured before and compared after). Sampling: every EXISTENCE-ONLY/CONDITIONAL-ONLY/TITLE-CONTRADICTION block in ADJUDICATE files + a seeded 5 % of BEHAVIOURAL (false-negative rate).

### 2c. `scripts/test-env.sh` — the environment contract

Absorbs and deletes `scripts/ci-setup-test-env.sh`. **KEEP-AND-ABSORB byte-exact**: the `:?` refusals with the CWE-798/#15 rationale (`:15-16`), the 32-byte `/dev/zero` key derivation (`:29`), the printed-phrase digest ring (`:38`), and the three-way single-quoting comparison (`:54-64`). Starts neither Postgres nor Redis (CI `services:`; the infra LXC locally): the contract is over **what** runs.

```

test-env.sh db [--reset]                       preflight → contamination check → migrate deploy → enable-app-role-login → seed → seed:e2e
```
