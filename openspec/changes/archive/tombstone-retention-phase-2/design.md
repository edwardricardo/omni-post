## Technical Approach

Tokenless (two Edward-authorized /.env windows at apply), no migration. Pure canonicalise+HMAC digest module and a batched CAS-per-row degrader (OutboxCleaner shape), wired as a daily `index.ts` tick under `withSystemContext`, keyed by an append-only env key ring validated at boot. Acceptance = the `deletion_record_overdue_plaintext` gauge draining to 0 on seeded back-dated rows.

## SPEC AMENDMENT REQUIRED (C2 + N4 — APPLIED to the materialized spec in this folder)

Req3 scenario 2's GIVEN narrowed to "a compatibility mapping **that full case folding does not itself collapse** (fullwidth, superscript form versus its decomposition)" — ligature removed from the distinct list (status F collapses U+FB01→fi; U+FB00-06/U+FB13-17/U+00DF/U+01C4 are the counterexample classes) — and the ligature added to the SAME-digest scenario's family.

## Data Flow

```
boot: env.ts (ring+pointer Zod, superRefine interlock, version-naming refusals)
  → composition root builds ring Map → setupCrisisUseCases registers degrader
  → index.ts registers daily tick
tick: withSystemContext("system:deletion-record-degrader")
  → findMany(retainUntil<now, name!=null, id notIn flagged, orderBy, take 100)
  → per row: canonicalizeName ──ok──> HMAC(ring[active]) ──> ONE CAS updateMany
  │                            └─flag/fail─> warn(id only), flagged.add(id)
  → repeat until batch<take after exclusion (≤50 batches; carry-over → next tick)
  → returns {degraded, flagged, failed} — the tick logs the triple
witness: /metrics scrape → gauge provider count → 0 drained; -1 UNKNOWN on failure
```
